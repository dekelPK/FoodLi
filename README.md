# FoodLi · ספר המתכונים שלי

ספר מתכונים אינטרנטי בעברית שנראה כמו ספר אמיתי. במחשב הוא נפתח כספר פתוח עם דפדוף בין העמודים, ובטלפון מוצג עמוד אחד בכל פעם עם החלקה.

## הוספת מתכון

כל המתכונים נמצאים בקובץ [`recipes.js`](recipes.js). הוראות למילוי כל שדה כתובות בראש הקובץ.

## תמונות ושיתוף

- ליד כל מתכון אפשר להוסיף תמונה. בגרסה שב־claude.ai התמונות נשמרות בספר ומוצגות לכל מי שפותח אותו. באתר הרגיל הן נשמרות בדפדפן בלבד. אפשר גם לשים קובץ בתיקייה `images/` ולהוסיף למתכון `photo: "images/שם-הקובץ.jpg"`.
- הכפתור "שיתוף לסטורי" יוצר תמונה בגודל 1080×1920 עם התמונה, שם המתכון והמצרכים.

## צפייה

- מקומית: פותחים את `index.html` בדפדפן.
- באינטרנט: Settings → Pages → Deploy from a branch → `master` / root.
